# 문의 처리 평가 세트

LLM 연결 후 문의 처리 기준대로 동작하는지 확인하기 위한 질문 24개입니다. 규정 문서는 `regs/`에 있습니다.

| 컬럼 | 내용 |
|---|---|
| id | A는 에이전트가 끝까지 처리할 질문, H는 사람에게 넘길 질문 |
| question | 구성원 질문 |
| asker | 질문한 구성원의 사번 (본인 근태 숫자가 필요한 질문만) |
| expected_route | `auto` 자동 답변, `handoff` 사람에게 넘김 |
| handoff_reason | 넘기는 이유: 승인과 결정, 재량 규정, 문서 간 충돌, 민감한 사안, 법적 분쟁 가능성, 근거 없음 (각 2개) |
| expected_source | 답변이나 판단의 근거가 되는 조항 |
| expected_numbers | 답변에 들어가야 하는 숫자. `rules.py` 계산 결과와 같아야 함 |

## 확인할 것

- 자동 답변과 넘김을 정답대로 나눴는지
- 근거 조항을 맞게 인용했는지
- 답변의 숫자가 규칙 계산 결과와 같은지 (LLM이 숫자를 새로 만들지 않는지)

## 규정에 일부러 넣어둔 경우

- 재량 조항: 근무시간 규정 제3조 3항, 제6조 2항
- 문서 간 충돌: 근무시간 규정 제7조 2항(이월 불가)과 2025년 이월 시범 운영 공지
- 규정에 없는 내용: 미사용 연차 보상, 재택근무
